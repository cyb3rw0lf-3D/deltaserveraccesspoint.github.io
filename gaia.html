Gaia

A self-hosted AI assistant running on my homelab.

What it is

Gaia runs Ollama on my own hardware — a private AI assistant I control end to end, rather than a hosted third-party service.

How it's reachable

  • No ports are opened on my router. The homelab server connects outbound to Cloudflare via a cloudflared tunnel.
  • Cloudflare Access requires me to log in before any request reaches the server at all.
  • Administrative (SSH) access is separate: key-only login for a normal user, with root locked behind a second factor.

Stack

  • Ollama (Docker)
  • Cloudflare Tunnel + Cloudflare Access
  • SSH key auth + PAM TOTP for sudo

Full setup instructions live in gaia/README.md in this repo.
